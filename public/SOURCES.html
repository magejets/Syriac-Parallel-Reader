Texts & sources

This reader presents all 39 books of the Jewish canon in Hebrew, alongside the complete ETCBC Peshitta text. It is an independent reader and has no affiliation with Parallel Plus, Sefaria, Open Scriptures or ETCBC.

Hebrew

The Masoretic text is the Westminster Leningrad Codex from the Open Scriptures Hebrew Bible Project. The project states that the WLC text is public domain; its lemma and morphology annotations are CC BY 4.0. Credit: Open Scriptures Hebrew Bible Project. Prefix separators have been removed for reading; verse punctuation is retained. The written form (ketiv) is displayed, with recorded qere available in word study. Cantillation can be hidden without hiding vowels.

Hebrew lexicon

Headwords, glosses, lexical roots, transliterations and BDB entries derive from Open Scriptures Hebrew Lexicon, licensed CC BY 4.0. The underlying 1906 BDB is public domain. This is their abridged transcription, not a new full BDB edition. XML markup has been converted to plain text; formatting and page references may be reduced. Root groups follow supplied lexical etymology, not guessed consonant matches. Prefix codes without lexical entries are explicitly marked.

Syriac

The full consonantal Syriac text comes from ETCBC/peshitta v0.5, based on Vetus Testamentum Syriace where published and Codex Ambrosianus for remaining books. The critical apparatus is not included. Word-level lexical and morphology annotations are added from the ETCBC / CACCHT Syriac Corpus v0.9 only where its verse and word forms match the full text; unannotated words remain readable without a lemma or morphology claim. Navigation retains the union of both source reference sets: unmatched Hebrew labels show a missing Syriac note, while Syriac-only labels appear as Syriac-only rows.

Use this bundled Syriac text only noncommercially. The ETCBC Peshitta data notice specifies CC BY-NC for the plain text and distinguishes it from MIT-licensed conversion software. This reader uses the text noncommercially and preserves attribution. The annotations remain covered by the upstream corpus terms; the source README and license are included with the project.

For the complete Peshitta dataset, cite van Peursen, Sikkel, Vlaardingerbroek, Roorda and Veldman, Old Testament Peshitta (2018). For the annotated corpus see its project DOI. Exact repository revisions and file hashes are recorded in the source lock. Contributor credits are preserved in the source README included with the project.

Attached morphemes have been joined using the source's trailer feature, preserving Syriac shaping. Lexemes remain in ETCBC transcription. Glosses are lexical aids, not translations of each occurrence. Word study includes an unvocalized consonant transliteration based on the base-letter repertoire in the Unicode Syriac chart. It does not infer vowels or pronunciation; unknown letters remain visible. No Syriac vowels, roots, cognate links or new word alignments have been invented. The Peshitta text and Hebrew Bible are paired by reference labels only, not by word-level alignment.

Fonts

Self-hosted Noto Sans Syriac (Estrangela) and Noto Serif Hebrew are distributed under the SIL Open Font License 1.1. Their copyright and reserved-name notices are preserved in Syriac OFL and Hebrew OFL. Fonts are cached with the reader shell. The writing style is a font choice, not a separate Unicode alphabet.

Optional Sefaria lookup

The reader contacts Sefaria's lexicon API only when you choose the online lookup button. This sends the Hebrew query and verse reference to Sefaria. It displays matching headwords and dictionary names with links, without saving definitions. Static BDB and concordance remain independent of the API, but require a connection. Bible chapters and study indexes load on demand and are not cached offline.

Sefaria licenses vary by resource and version; see its copyright and data-use guidance. A future full-entry provider must check resource-specific licenses, sanitize definitions, and handle ambiguity, network failures and offline fallbacks. An API match does not guarantee the correct sense for this verse.

Alignment & reproducibility

The export contains 23,213 Hebrew reference rows across all 39 books. Pairs use matching chapter/verse labels; 207 Hebrew references have no exact Syriac label in the dataset and show a missing-source note. These differences have not undergone a complete philological alignment audit and may include versification differences. Word positions are never used to infer translation equivalents. Occurrence indexes are split by book, and Hebrew counts follow the displayed ketiv. Multi-component root groups may include more than one token within a displayed word.
